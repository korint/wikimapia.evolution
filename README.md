# Wikimapia Development Continues

This repo is for ideas about Wikimapia evolution and development.
Main Wikimapia Coordiantion Chat Group https://t.me/wikimapia_org



We started Wikimapia almost twenty years ago, in 2006. Since then, millions of places have been added and edited by people around the world, creating a geographic record that would be extremely difficult to reproduce today.

Keeping a project of this scale running for so many years has required continuous work. Wikimapia is a large and complex system, and maintaining its infrastructure, database, and legacy codebase has always been both resource-intensive and costly. That work has continued throughout the years, even as active development of new features gradually stalled.

Recently, however, the situation has started to change. New development tools, including agentic coding tools, make it much more practical to work with a large legacy system, understand its existing code, and improve it gradually rather than rebuild everything from scratch. This gives us an opportunity to develop Wikimapia more actively again.

The first priority is very practical: to make Wikimapia easier to edit. We want to simplify the work of people who continue adding, correcting, and maintaining information on the map, remove unnecessary friction, and gradually improve the tools available to editors.

A more detailed development roadmap will be prepared later. For now, the important thing is that Wikimapia is moving forward again.

After two decades, there is a great deal worth preserving, and still a lot that can be improved.

Wikimapia continues.
